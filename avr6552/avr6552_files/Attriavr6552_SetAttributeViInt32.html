AVR6552_ATTR_AUTO_ZERO

Data Type: ViInt32
Description: Specifies the auto-zero mode.  In general, the auto-zero capability of a DMM normalizes all measurements based on a Zero Reading.  When auto-zeroing is enabled, the DMM internally disconnects the input signal and takes a Zero Reading.  The DMM then subtracts the Zero Reading from the measurement.  This prevents offset voltages present in the DMM's input circuitry from affecting measurement accuracy.
Attribute Value: 1250332
Values
AVR6552_VAL_AUTO_ZERO_OFF Disables the DMM from taking any more Zero Readings.  The DMM subtract the last Zero Reading from all subsequent values it measures.
AVR6552_VAL_AUTO_ZERO_ON Configures the DMM to take a Zero Reading for each measurement.  The DMM subtracts the Zero Reading from the value it measures.
AVR6552_VAL_AUTO_ZERO_ONCE Configures the DMM to take a Zero Reading immediately.  The DMM then subtracts this Zero Reading from all subsequent values it measures.

AVR6552_ATTR_CACHE

Data Type: ViBoolean
Description: Specifies whether to cache the value of attributes.  When caching is enabled, the instrument driver keeps track of the current instrument settings and avoids sending redundant commands to the instrument.  Thus, you can significantly increase execution speed.
The instrument driver can choose always to cache or never to cache particular attributes regardless of the setting of this attribute.
The default value is VI_TRUE.   Use the avr6552_InitWithOptions function to override this value.
Attribute Value: 1050004

AVR6552_ATTR_INTERCHANGE_CHECK

Data Type: ViBoolean
Description: Specifies whether to perform interchangeability checking and retrieve interchangeability warnings when you call avr6552_Initiate or avr6552_Read.
The default value is VI_FALSE.
Interchangeability warnings indicate that using your application with a different instrument might cause different behavior.  You call avr6552_GetNextInterchangeWarning to extract interchange warnings.  Call the avr6552_ClearInterchangeWarnings function to clear the list of interchangeability warnings without reading them.
Interchangeability checking examines the attributes in a capability group only if you specify a value for at least one attribute within that group.  Interchangeability warnings can occur when an attribute affects the behavior of the instrument and you have not set that attribute, or the attribute has been invalidated since you set it.
Attribute Value: 1050021

AVR6552_ATTR_RANGE

Data Type: ViReal64
Description: Specifies the measurement range.  You use positive values to represent the absolute value of the maximum expected measurement.  The value is in units appropriate for the current value of the AVR6552_ATTR_FUNCTION attribute.  For example, when you set the AVR6552_ATTR_FUNCTION attribute to AVR6552_VAL_DC_VOLTS, the units are volts.  For example, setting this attribute to 10.0 configures the DMM to measure DC voltages from -10.0 to +10.0 volts.
Negative values are reserved for controlling the DMM's auto-ranging capability.
- AVR6552_VAL_AUTO_RANGE_ON (-1.0) - Configures the DMM to calculate the range before each measurement automatically.
For AVR6552, When you set this attribute to AVR6552_VAL_AUTO_RANGE_ON, you cannot obtain the actual range the DMM is currently using.
Note:  
(1)  For frequency or diode measurements, this attribute must be set to AVR6552_VAL_AUTO_RANGE_ON.    
(2) This attribute must be set to  AVR6552_VAL_AUTO_RANGE_ON in burst measurement mode.
Attribute Value: 1250002
