avr6552_ConfigureSampleRate

ViStatus avr6552_ConfigureSampleRate (ViSession instrumentHandle, ViInt32 sampleRate, ViReal64 integralTime_milliseconds);

Purpose

This function configures the common attributes of sample rate for the DMM.  These attributes include the sample rate and integral time.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the avr6552_init or avr6552_InitWithOptions function.  The handle identifies a particular instrument session.
Default Value:  None
sampleRate ViInt32 Pass the sample rate you want the DMM to use.  The driver sets the attribute AVR6552_ATTR_SAMPLE_RATE to this value.
For AVR6552:
Valid Values:
AVR6552_VAL_FAST
AVR6552_VAL_MED
AVR6552_VAL_SLOW    (Default)
AVR6552_VAL_LONGIT
For AVR6552T and AVR6552T-R:
Valid Values:
AVR6552_VAL_FAST
AVR6552_VAL_MED
AVR6552_VAL_SLOW    (Default)
Note:  This attribute can be set to AVR6552_VAL_LONGIT only when the measurement function is set to DC Volts or DC Current.
integralTime_milliseconds ViReal64 Pass the integral time you want the DMM to use for the long-it sample rate.  Express this value in milliseconds.  The driver sets the AVR6552_ATTR_INTEGRAL_TIME attribute to this value.
Valid Manual Range:  100.0 - 60000.0 (milliseconds)
Default Value: 100.0 (milliseconds)
Notes:
(1) This attribute is only supported by AVR6552.
(2) This attribute has no effect on the behavior of the DMM if the sample rate is not set to long-it.   

Return Value

Name Type Description
status ViStatus Returns the status code of this operation.  The status code  either indicates success or describes an error or warning condition.  You examine the status code from each call to an instrument driver function to determine if an error occurred.
To obtain a text description of the status code, call the avr6552_error_message function.  To obtain additional information about the error condition, call the avr6552_GetError function.  To clear the error information from the driver, call the avr6552_ClearError function.
The general meaning of the status code is as follows:
Value                  Meaning
-------------------------------
0                      Success
Positive Values        Warnings
Negative Values        Errors
