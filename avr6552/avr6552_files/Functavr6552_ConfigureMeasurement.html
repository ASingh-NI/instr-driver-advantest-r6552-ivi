avr6552_ConfigureMeasurement

ViStatus avr6552_ConfigureMeasurement (ViSession instrumentHandle, ViInt32 measurementFunction, ViReal64 range, ViReal64 resolution_absolute);

Purpose

This function configures the common attributes of the DMM.  These attributes include the measurement function, maximum range, and the absolute resolution.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the avr6552_init or avr6552_InitWithOptions function.  The handle identifies a particular instrument session.
Default Value:  None
measurementFunction ViInt32 Pass the measurement function you want the DMM to perform.  The driver sets the AVR6552_ATTR_FUNCTION attribute to this value.  
Valid Values:
Model AVR6552:
AVR6552_VAL_DC_VOLTS           - DC Volts (Default)
AVR6552_VAL_AC_VOLTS           - AC Volts
AVR6552_VAL_DC_CURRENT         - DC Current
AVR6552_VAL_AC_CURRENT         - AC Current
AVR6552_VAL_2_WIRE_RES         - 2-Wire Resistance
AVR6552_VAL_LP_2_WIRE_RES      - Low Power 2-Wire Resistance
AVR6552_VAL_4_WIRE_RES         - 4-Wire Resistance
AVR6552_VAL_LP_4_WIRE_RES      - Low Power 4-Wire Resistance
AVR6552_VAL_AC_PLUS_DC_VOLTS   - AC plus DC Volts
AVR6552_VAL_AC_PLUS_DC_CURRENT - AC plus DC Current
AVR6552_VAL_FREQ               - Frequency
AVR6552_VAL_DIODE              - Diode
Model AVR6552T:
AVR6552_VAL_DC_VOLTS           - DC Volts (Default)
AVR6552_VAL_2_WIRE_RES         - 2-Wire Resistance
AVR6552_VAL_4_WIRE_RES         - 4-Wire Resistance
AVR6552_VAL_LP_2_WIRE_RES      - Low Power 2-Wire Resistance
AVR6552_VAL_LP_4_WIRE_RES      - Low Power 4-Wire Resistance
Model AVR6552T-R:
AVR6552_VAL_DC_VOLTS           - DC Volts (Default)
AVR6552_VAL_2_WIRE_RES         - 2-Wire Resistance
AVR6552_VAL_4_WIRE_RES         - 4-Wire Resistance
AVR6552_VAL_RIPPLE_VOLTS       - Ripple Volts
Notes:  
(1)  This attribute can only be set to DC Volts or DC Current when the sample rate is AVR6552_VAL_LONGIT.
(2)  This attribute can only be set to DC Volts, DC Current, 2-Wire resistance, or LP 2-Wire resistance if the sample mode is AVR6552_VAL_BURST.
range ViReal64 Pass the measurement range you want to use.  The driver sets the AVR6552_ATTR_RANGE attribute to this value.  
Use positive values to represent the absolute value of the maximum expected measurement.  The value must be in units appropriate for the Measurement Function.  For example, when you set the Measurement Function to AVR6552_VAL_DC_VOLTS, you must specify the Range in volts.  Setting this parameter to 10.0 configures the DMM to measure DC voltages from -10.0 to +10.0 volts.
The driver reserves special negative values for controlling the DMM's auto-ranging capability.
Defined Values:
AVR6552_VAL_AUTO_RANGE_ON  (-1.0) - Auto-range On
Valid Manual Range:  The valid manual range depends on the measurement function you select with the AVR6552_ATTR_FUNCTION attribute.

Notes:
(1) For AVR6552, the auto range is always on when the measurement function is set to AVR6552_VAL_FREQ, and the range value is fixed value 3000mv when the measurement function is set to AVR6552_VAL_DIODE.
resolution_absolute ViReal64 Pass your desired measurement resolution in absolute units. The driver sets the AVR6552_ATTR_RESOLUTION_ABSOLUTE attribute to this value.
Setting this parameter to lower values increases the measurement accuracy.  Setting this parameter to higher values increases the measurement speed.
