avr6552_ConfigureACBandwidth

ViStatus avr6552_ConfigureACBandwidth (ViSession instrumentHandle, ViReal64 ACMinimumFrequency_Hz, ViReal64 ACMaximumFrequency_Hz);

Purpose

This function configures the AC minimum and maximum frequency for AC voltage or AC current measurements.
This function affects the behavior of the instrument only if the AVR6552_ATTR_FUNCTION attribute is set to an AC voltage or AC current measurement.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the avr6552_init or avr6552_InitWithOptions function.  The handle identifies a particular instrument session.
Default Value:  None
ACMinimumFrequency_Hz ViReal64 Pass the minimum expected frequency component of the input signal.  The units are hertz.  The driver sets the AVR6552_ATTR_AC_MIN_FREQ attribute to this value.
This parameter affects the DMM only when you set the Measurement Function parameter to AC measurement.
Valid Range: 20.0 - 300.0 Hz
Default Value: 20.0 Hz
ACMaximumFrequency_Hz ViReal64 Pass the maximum expected frequency component of the input signal.  The units are hertz.  The driver sets the AVR6552_ATTR_AC_MAX_FREQ attribute to this value.
This parameter affects the DMM only when you set the Measurement Function parameter to AC measurement.
The maximum valid value of this attribute depends on the measurement function.
Valid Range:  
For AC voltage measurements: 300.0 - 300000.0 Hz
For AC current measurements: 300.0 - 5000.0 Hz
Default Value: 300000.0 Hz

Return Value

Name Type Description
status ViStatus Returns the status code of this operation.  The status code  either indicates success or describes an error or warning condition.  You examine the status code from each call to an instrument driver function to determine if an error occurred.
To obtain a text description of the status code, call the avr6552_error_message function.  To obtain additional information about the error condition, call the avr6552_GetError function.  To clear the error information from the driver, call the avr6552_ClearError function.

Value                  Meaning
-------------------------------

Positive Values        Warnings
Negative Values        Errors
