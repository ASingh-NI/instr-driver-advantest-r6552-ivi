avr6552_ConfigureTrigger

ViStatus avr6552_ConfigureTrigger (ViSession instrumentHandle, ViInt32 triggerSource, ViReal64 triggerDelay_sec);

Purpose

This function configures the common DMM trigger attributes.  These attributes include the trigger source and trigger delay.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the avr6552_init or avr6552_InitWithOptions function.  The handle identifies a particular instrument session.
Default Value:  None
triggerSource ViInt32 Specify the trigger source.  The driver sets the AVR6552_ATTR_TRIGGER_SOURCE attribute to this value.  
Valid Values:
AVR6552_VAL_IMMEDIATE       - Internal Trigger (Default)
Note:
(1) This attribute affects the behavior of the instrument only when the AVR6552_ATTR_SAMPLE_MODE attribute is set to AVR6552_VAL_FREE_RUN. For other sample modes, the instrument will only trigger when the avr6552_ForceTrigger function is called.
triggerDelay_sec ViReal64 The trigger delay specifies the length of time the DMM waits after it receives the trigger and before it takes a measurement.
Valid Manual Range:  0.0
Default Value: 0.0 (seconds)
Note:  This attribute does not affect the behavior of the DMM and exists only for class compliance.

Return Value

Name Type Description
status ViStatus Returns the status code of this operation.  The status code  either indicates success or describes an error or warning condition.  You examine the status code from each call to an instrument driver function to determine if an error occurred.
To obtain a text description of the status code, call the avr6552_error_message function.  To obtain additional information about the error condition, call the avr6552_GetError function.  To clear the error information from the driver, call the avr6552_ClearError function.
The general meaning of the status code is as follows:
Value                  Meaning
-------------------------------
0                      Success
Positive Values        Warnings
Negative Values        Errors
This driver defines the following status codes:
Status    Description
-------------------------------------------------
No defined status codes.
