avr6552_ConfigureNull

ViStatus avr6552_ConfigureNull (ViSession instrumentHandle, ViBoolean enable, ViReal64 nullOffset);

Purpose

This function enables or disables the null calculation and configures null offset.
The null calculation generates a measurement value less a null offset.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the avr6552_init or avr6552_InitWithOptions function.  The handle identifies a particular instrument session.
Default Value:  None
enable ViBoolean Enable or disable the null calculation. The driver uses this value to set the AVR6552_ATTR_NULL_ENABLED attribute.
Valid Range:
VI_TRUE  (1) - Enable
VI_FALSE (0) - Disable (Default)
nullOffset ViReal64 Pass the null offset you want the DMM to use.  The driver sets the AVR6552_ATTR_NULL_OFFSET attribute to this value.
The instrument subtracts the null offset form each subsequent measurement.
The null offset cannot be set if the null operation is not enabled. You must set the value of the AVR6552_ATTR_NULL_ENABLED  to VI_TRUE before setting this attribute.
Valid Values:  -999999.E+6 - +999999.E+6
Default Value:  0.0
Note:
(1) This attribute does not affect the behavior of the instrument if the value of the AVR6552_ATTR_NULL_ENABLED attribute is VI_FALSE.
(2) This parameter is ignored if the value of the 'Enable' parameter is VI_FALSE.

Return Value

Name Type Description
status ViStatus Returns the status code of this operation.  The status code  either indicates success or describes an error or warning condition.  You examine the status code from each call to an instrument driver function to determine if an error occurred.
