avr6552_ReadBurstMultiPoint

ViStatus avr6552_ReadBurstMultiPoint (ViSession instrumentHandle, ViInt32 maximumTime_ms, ViInt32 arraySize, ViReal64 _VI_FAR readingArray[], ViPInt32 actualNumberOfPoints);

Purpose

Call this function to obtain a measurement if the instrument is in the Burst sample mode. This function sends a software trigger to the instrument, waits for the DMM to return to the Idle state, and returns an array of measured values.  The number of measurements the DMM takes is determined by the  AVR6552_ATTR_BURST_COUNT attribute.
Notes:
(1) After this function executes, each element in the Reading Array parameter is an actual reading or a value indicating that an over-range condition occurred.
(2) If an over-range condition occurs, the corresponding Reading Array element contains an IEEE defined NaN (Not a Number) value and the function returns AVR6552_WARN_OVER_RANGE (0x3FFA2001).
(3) You can test each element in the Reading Array parameter for over-range with the avr6552_IsOverRange function.
(4) This function is supported only by the AVR6552.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the avr6552_init or avr6552_InitWithOptions function.  The handle identifies a particular instrument session.
Default Value:  None
maximumTime_ms ViInt32 Pass the maximum length of time in which to allow the multi-point read operation to complete.  Express this value in milliseconds.  
If the operation does not complete within this time interval, the function returns the AVR6552_ERROR_MAX_TIME_EXCEEDED (0xBFFA2003) error code.  When this occurs, you can call avr6552_Abort to cancel the multi-point read operation and return the instrument to the Idle state.  
Defined Values:
AVR6552_VAL_MAX_TIME_INFINITE (-1)             AVR6552_VAL_MAX_TIME_IMMEDIATE (0)           
Default Value: 5000 (ms)
Notes:
(1) The Maximum Time parameter affects only this function.  It has no effect on other timeout parameters or attributes.
arraySize ViInt32 Pass the number of elements in the Reading Array parameter.
Default Value: None
Output
Name Type Description
readingArray ViReal64[] Returns an array of the most recent measurement values.  The value you specify for the Measurement Function parameter of the avr6552_ConfigureMeasurement function determines the units of this parameter as shown in the following table.
DC Volts           - volts
AC Volts           - volts
DC Current         - amperes
AC Current         - amperes
2-Wire Resistance  - ohms
4-Wire Resistance  - ohms
LP 2-Wire Resistance - ohms
LP 4-Wire Resistance - ohms
AC plus DC Volts   - volts
AC plus DC Current - amperes
Frequency          - hertz
Diode              - none
Ripple Volts       - volts
Notes:
(1) The size of the Reading Array must be at least the size you specify for the Array Size parameter.
(2) If an over-range condition occurs, the corresponding Reading Array element contains an IEEE defined NaN (Not a Number) value and the function returns AVR6552_WARN_OVER_RANGE (0x3FFA2001).
(3) You can test each element in the Reading Array parameter for over-range with the avr6552_IsOverRange function.
actualNumberOfPoints ViInt32 (passed by reference) Indicates the number of measured values the function places in the Reading Array parameter.

Return Value

Name Type Description
status ViStatus Returns the status code of this operation.  The status code  either indicates success or describes an error or warning condition.  You examine the status code from each call to an instrument driver function to determine if an error occurred.
To obtain a text description of the status code, call the avr6552_error_message function.  To obtain additional information about the error condition, call the avr6552_GetError function.  To clear the error information from the driver, call the avr6552_ClearError function.
