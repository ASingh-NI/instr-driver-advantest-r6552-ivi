avr6552_ConfigureRippleVoltsFilter

ViStatus avr6552_ConfigureRippleVoltsFilter (ViSession instrumentHandle, ViInt32 highPassFilter, ViInt32 lowPassFilter);

Purpose

This function configures the common attributes of ripple voltage measurement for the DMM.  These attributes include the high pass filter and the low pass filter.
Notes:
(1) This function is supported only by AVR6552T-R.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the avr6552_init or avr6552_InitWithOptions function.  The handle identifies a particular instrument session.
Default Value:  None
highPassFilter ViInt32 Pass the high pass filter you want the DMM to use to measure ripple volts.  The unit for this attribute is hertz.  The driver sets the attribute AVR6552_ATTR_HIGH_PASS_FILTER to this value.
Valid Range: 1000.0, 10000.0, 100000.0 Hz
Defined Values:
AVR6552_VAL_FILTER_OFF - Filter Off
Default Value: AVR6552_VAL_FILTER_OFF
Notes:
(1) This attribute is supported only by AVR6552T-R.
lowPassFilter ViInt32 Pass the low pass filter you want the DMM to use to measure ripple volts.  The unit for this attribute is hertz.  The driver sets the attribute AVR6552_ATTR_LOW_PASS_FILTER to this value.
Valid Range: 1000.0, 10000.0, 100000.0, 1000000.0 Hz
Defined Values:
AVR6552_VAL_FILTER_OFF - Filter Off
Default Value: AVR6552_VAL_FILTER_OFF
Notes:
(1) This attribute is supported only by AVR6552T-R.
