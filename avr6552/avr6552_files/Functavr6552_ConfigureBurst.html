avr6552_ConfigureBurst

ViStatus avr6552_ConfigureBurst (ViSession instrumentHandle, ViInt32 burstCount, ViInt32 delayedTrigger);

Purpose

This function configures the attributes for measurements in burst sample mode.  These attributes include the burst count and delayed trigger.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the avr6552_init or avr6552_InitWithOptions function.  The handle identifies a particular instrument session.
Default Value:  None
burstCount ViInt32 Pass the burst count you want the DMM to use.  The driver sets attribute AVR6552_ATTR_BURST_COUNT to this value.
Valid Values:  1000, 2000, 3000, 4000, 5000, 6000, 7000, 8000,    
9000, 10000
Default Value:  1000
Notes:
(1) This attribute affects the behavior of the instrument only if the AVR6552_ATTR_SAMPLE_MODE attribute is set to AVR6552_VAL_BURST.
delayedTrigger ViInt32 Pass the delayed trigger setting you want the DMM to use.  The driver sets the attribute AVR6552_ATTR_DELAYED_TRIGGER to this value.
In Burst sample mode, the delayed trigger setting determines the values in effect to be stored in memory before and after the trigger, in another word, the delayed trigger setting determines the trigger position.
Valid Values:  0 (Trigger off), 25, 50, 75
Default Value: 0 (Trigger off)
Notes:
(1) This attribute affects the behavior of the instrument only if the AVR6552_ATTR_SAMPLE_MODE attribute is set to AVR6552_VAL_BURST.

Return Value

Name Type Description
status ViStatus Returns the status code of this operation.  The status code  either indicates success or describes an error or warning condition.  You examine the status code from each call to an instrument driver function to determine if an error occurred.
To obtain a text description of the status code, call the avr6552_error_message function.  To obtain additional information about the error condition, call the avr6552_GetError function.  To clear the error information from the driver, call the avr6552_ClearError function.
